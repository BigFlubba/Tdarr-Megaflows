## Normalize Jellyfin Audio Theme Files

### Description

This flow will process any Jellyfin audio theme file you throw at it to normalize it to a comfortable listening level.

### Setup

> [!IMPORTANT]
> For this flow to be effective, you need to set your library path as follows: `/path-to-your-jellyfin/movies` & `/path-to-your-jellyfin/tv-shows`, or any path to a Jellyfin library that has theme audio files saved.

1. Download a copy of the flow
2. Copy the JSON to your clipboard
3. Import the JSON into a new flow
4. Set your libraries to use the new flow
